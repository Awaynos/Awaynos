01 — Обо мне

Делаю инструменты,
к которым хочется возвращаться.

Я Awaynos — разработчик, который любит маленькие задачи с большим эффектом. Прозрачное окно поверх игры, переводчик по Ctrl+Q, колесо сообщений под курсором — всё это про то, чтобы убрать лишний шаг между человеком и задачей.

Работаю на стыке десктопа, автоматизации и веба. Выбираю технологию под задачу: Python и Qt — когда нужна скорость разработки, C# и Win32 — когда важна нативность, TypeScript — когда продукт должен жить в браузере.

Начинал с небольших утилит для себя — и постепенно дошёл до проектов с релизами, звёздами на GitHub и живыми пользователями. До сих пор считаю, что лучший интерфейс — тот, о котором не приходится думать.

03 — Подход

Не просто код.
Готовый инструмент.

Мне важно, чтобы проект не остался папкой с исходниками, а превратился в вещь, которой удобно пользоваться каждый день.

01 / 03

Сначала боль

Разбираюсь, что именно мешает: лишние клики, медленный интерфейс, неудобный сценарий. Стек выбираю под задачу.

02 / 03

Быстрый прототип

Собираю рабочий MVP, проверяю на реальных задачах и выкидываю всё, что не помогает человеку.

03 / 03

Релиз и детали

Portable-сборка, горячие клавиши, тёмная тема и документация. Проект должен работать без инструкции на 40 страниц.

04 — Навыки

Инструменты под задачу.

Не привязываюсь к одному стеку. Python — для скорости, C# — для нативности, TypeScript — для веба.

Telegram и сети

Боты, пользовательские сессии, MTProto-прокси и обход блокировок — там, где обычного Bot API уже недостаточно.

Стек

Bot APITelethonMTProtoWebSocketTCP / HTTPCloudflare WorkersFake TLSPROXY protocol v1Обход DPI

Что умею

  • Пишу ботов на Bot API и автоматизацию на пользовательских сессиях Telethon.
  • Разбираюсь в MTProto: DC, transport, secret и прокси-подключения.
  • Поднимаю WebSocket-туннели и fallback на Cloudflare / CF-Worker.
  • Маскирую трафик под HTTPS (Fake TLS), работаю с PROXY protocol.
  • Делаю массовые проверки и парсинг с учётом лимитов Telegram.
