04 / Обо мне

Начинал с небольших утилит для себя — сейчас у проектов есть релизы и живые пользователи. Люблю задачи, где нужно убрать один лишний шаг: хоткей вместо меню, карта поверх игры, колесо вместо десяти сообщений.

Работаю на стыке десктопа, автоматизации и веба. Python и Qt — когда важна скорость разработки, C# и Win32 — когда нужна нативность, TypeScript — когда продукт живёт в браузере. Развиваю коммерческую CRM для заказчика и поддерживаю свои приложения.
